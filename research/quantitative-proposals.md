# Quantitative research proposals

These are possible extensions of the existing research. No analysis below has been completed or accepted as a project assignment.

## Precise Mass: coding sensitivity

Measure how descriptive results change under defensible rules for uncertain capabilities and fielding dates. Begin with a fixed version of the reviewed dataset. Separate unknown AI capability from an explicit negative; distinguish a contract, a delivery, and operational fielding. Compare summaries with unresolved observations excluded, included under a stated alternative rule, and displayed separately.

The output would be a table of counts and changes attributable to each coding decision. It would describe measurement sensitivity, not establish which undocumented capability is present.

## Precise Mass: commercial activity and observed international spread

Ask whether producers with documented commercial activity appear in more country-system records in the collected sample. Resolve producer aliases and system variants first. Define separately whether a firm sells related commercial products or has any commercial business.

Count distinct observed countries for each defined producer or system, and report missing commercial-activity coding. These records do not represent a complete global inventory. The result would be an association within the collected sample, not a causal effect, market share, sales volume, or a measure of adoption success.

## Precise Mass: observed import relationships

Construct a network of documented producer-country relationships using confirmed import coding and source dates. Keep joint assembly and unclear origin explicit. Deduplicate repeated systems and distinguish planned orders from receipts.

Summaries could show concentration in the documented relationships and how conclusions change when ambiguous cases are omitted. A count of relationships cannot stand in for units delivered, contract values, or dependence across an entire country's force.

## Survey research: reproduce published results

Start with the [survey research notes](surveys/README.md). Reproduce a small set of military-use results with question text, subgroup, denominator, weighting, and source location. Compare studies only where the constructs are aligned; keep comfort, willingness to work, forecasts, and policy preferences separate.

If respondent-level work is desired, the public ESPAI dataset offers a possible framing-replication exercise. Its randomized wording can support a carefully defined comparison after the questionnaire, assignment mechanism, and missingness are checked. It would address broader AI forecasting rather than directly answering military-attitudes questions.

The Anthropic test needs its actual instrument before a quantitative task can be specified. A proposed analysis should remain distinct from completed work in meeting updates and project records.
